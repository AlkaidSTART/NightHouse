## 声音卡

- **年龄与身份**：61 岁男性，家庭医生，服务家族二十年。
- **性格依据**：`src/content/npcs.ts`——温和、疲惫、用医学术语转移话题、防御性反问。
- **表演要求**：语速中等偏慢，句尾略哑；被追问时用术语堆叠换气口，而不是提高音量。疲惫要一直在，但不要虚弱到听不清。
- **禁忌**：不要演成阴险反派或醉酒老者；他的问题在于回避，不在于恶意。
- **称谓**：3 条台词含 `{honorific}` 占位（「先生 / 小姐」），是他维持职业礼貌的方式。

## 1. 覆盖范围

- 全部 `npcId: 'npc_doctor'` 的 `lines` 中 `speaker: 'npc'` 的台词。
- 全部 `reenterLines`（2 条，文件名后缀 `_R`）。
- **不包含**：同一节点里的旁白（归 `VO_Narrator`）、玩家选项文本（未配音）。

建议首条样音：`npc_doctor_intro`（两句，含称谓与"他这一年睡得不好"的试探，能一次验证温和与防御两层）。

## 2. 技术规格

遵循 [../README.md](../README.md) 的通用技术规格，本资产额外要求：

| 项目 | 要求 |
|---|---|
| 音量基准 | −18 LUFS；与亚瑟同档，不要因为"年老"压低响度 |
| 医学术语 | 「后枕部挫伤」「瞳孔散大」等词必须清晰，不要含糊带过 |
| 称谓 | 若保留两版，`textAlt` 列另录一条，按 `player.honorific` 选择文件 |
| 一致性 | 全部 35 条同一次录音/同一条音色配置完成 |
