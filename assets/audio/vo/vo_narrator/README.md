## 声音卡

- **定位**：无性别倾向、低干扰的叙述声，不做角色表演。
- **表演要求**：陈述句为主，语速稳定，句尾下沉；不煽情、不加重音强调线索。
- **禁忌**：不要用"恐怖故事旁白腔"、不要气声耳语、不要在关键物证上提高音量——线索靠文本和玩家自己发现。

## 1. 覆盖范围

- 全部 `speaker: 'narration'` 的对话台词（13 条）。
- **不包含**：序章旁白（约 285 字）、三结局旁白（约 1117 字）、检视面板正文（约 3915 字）。若决定统一旁白配音，需另立批次并在此登记；检视文本建议保持纯文字。

## 2. 技术规格

遵循 [../README.md](../README.md) 的通用技术规格，本资产额外要求：

| 项目 | 要求 |
|---|---|
| 音量基准 | −20 LUFS，比 NPC 台词低约 2 dB，保证旁白永远不压台词 |
| 字幕 | 旁白与 NPC 台词共用对话面板，逐字一致是硬要求 |
| 一致性 | 若结局与序章也配音，必须同一音色、同一语速基准 |

## 5. 备注

- 对话内旁白与检视文本是两套呈现方式：前者跟着对话节奏逐句出现，后者是玩家主动阅读的纸面文本。不要因为"都叫旁白"就批量配音，否则会把阅读节奏变成听读节奏。
