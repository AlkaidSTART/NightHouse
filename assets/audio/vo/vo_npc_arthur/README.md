## 声音卡

- **年龄与身份**：32 岁男性，长子、现任家主。
- **性格依据**：`src/content/npcs.ts` 的 `personality`——克制、回避主语、长期失眠、**越接近真相句子越短**。
- **表演要求**：低音量、气息浅、句子收尾快；恐惧不外放，用停顿和缩短句子表达。对质段落（`npc_arthur_confront_*`）允许音量下降而不是升高。
- **禁忌**：不要嘶吼、不要哭腔、不要用气声演"阴森"；亚瑟始终在维持体面。
- **与玩家关系**：主角艾略特·维恩是伊芙琳的表亲、家族边缘成员；亚瑟对玩家礼貌但保持距离，称谓与语气按"多年未见、需要你签字"的关系处理。
