## 声音卡

- **年龄与身份**：58 岁女性，在宅中服务三十年。
- **性格依据**：`src/content/npcs.ts`——寡言、敬语、省略主语、习惯站在门边。
- **表演要求**：语速偏慢，停顿比情绪重要；句子常不完整，收尾轻。她陈述事实时不加解释，也不主动补全。
- **禁忌**：不要演成刻薄的管家，也不要演成可怜的老人；她的克制来自职业习惯，不是恐惧。
- **称谓**：4 条台词含 `{honorific}` 占位（「先生 / 小姐」），是她的敬语核心，不能省略。

## 1. 覆盖范围

- 全部 `npcId: 'npc_housekeeper'` 的 `lines` 中 `speaker: 'npc'` 的台词。
- 全部 `reenterLines`（2 条，文件名后缀 `_R`）。
- **不包含**：同一节点里的旁白（归 `VO_Narrator`）、玩家选项文本（未配音）。

建议首条样音：`npc_housekeeper_intro`（三句，含称谓，能同时验证敬语语气与称谓处理）。

## 2. 技术规格

遵循 [../README.md](../README.md) 的通用技术规格，本资产额外要求：

| 项目 | 要求 |
|---|---|
| 音量基准 | −18 LUFS；整体可比亚瑟低 1 dB，符合她压低声音的说话习惯 |
| 停顿 | 保留她句中的迟疑停顿，但不要拉长到 0.8 秒以上，避免玩家以为卡住 |
| 称谓 | 若保留两版，文件名不变、`textAlt` 列另录一条；接入时按 `player.honorific` 选择文件 |
| 一致性 | 全部 54 条同一次录音/同一条音色配置完成 |
