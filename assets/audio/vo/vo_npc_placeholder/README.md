# VO_NPC_Placeholder · NPC 语音（占位）

> 资产类型：语音 ｜ 优先级：待定 ｜ 状态：待音频方案确认

| 项目 | 内容 |
|---|---|
| 使用位置 | NPC 对话（若启用配音） |
| 依赖 / 复用 | 对话节点与音频方案确认后接入 |

## 快速使用

该资产仅作占位，暂不制作正式语音。先确认 MVP 是否启用配音，再决定录制或生成方案。

## 1. 生成提示词

> NPC 身份与台词已由故事线 V0.7 确认；但配音风格、语言和是否全量配音尚未决定，不要提前生成正式语音。

## 2. 用途

为 NPC 对话提供语音表现；是否启用和覆盖范围待音频方案确认。

## 3. 技术规格

| 项目 | 要求 |
|---|---|
| 时长 | 按对话节点确定 |
| 格式 | 源文件 WAV：单声道 / 48 kHz / 24-bit；运行文件 OGG Vorbis：单声道 / 48 kHz |
| 响度 | 对白约 -18 LUFS |
| 循环 | 不循环 |
| 运行路径 | public/assets/audio/vo/VO_NPC_Placeholder.ogg |

## 4. 生成后检查

- [ ] 时长、源文件格式、运行格式和响度符合规格
- [ ] 无削波、爆音和明显底噪
- [ ] 循环接缝无缝（如要求）
- [ ] 没有意外的音乐、人声或可识别版权内容
- [ ] 在耳机和桌面音箱上分别试听
- [ ] 浏览器中通过 `AudioManager` 播放测试通过
- [ ] 来源与许可证已记录
