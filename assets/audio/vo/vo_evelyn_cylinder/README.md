## 声音卡

- **年龄与身份**：27 岁女性，伊芙琳·阿什克罗夫特，已故；玩家（艾略特·维恩）的表亲。
- **表演要求**：对着留声机说话，不是对玩家说话。克制，但能听出哭过；句子之间有真实的换气，因为她在录一段可能没人会听的留言。
- **禁忌**：不要表演式崩溃、不要尖叫、不要甜腻。最后一句提到"艾略特"时要停顿，像在确认这个名字能不能说出口。
- **时代质感**：1897 年蜡筒录音，声音偏窄带、底噪明显。**建议录干声**，蜡筒质感由 `SFX_Gramophone_Play` 与 `SFX_Gramophone_Hiss_Loop` 在运行时叠加，不要把窄带与失真烘进语音文件——否则换播放设备后无法调整。

## 1. 覆盖范围

- `INT_prop_phonograph` 中 `item.cylinder` 变体的 5 段引用文本，按 `P01`–`P05` 顺序连续播放。
- **不包含**：检视面板的前后描述文字（保留纯文字）。

## 2. 技术规格

遵循 [../README.md](../README.md) 的通用技术规格，本资产额外要求：

| 项目 | 要求 |
|---|---|
| 音量基准 | −18 LUFS；若运行时叠加蜡筒底噪，底噪单独走 SFX 总线，不并入语音文件 |
| 段间 | 段与段之间保留 300–500 ms 停顿，接入时按段顺序播放，不做无缝拼接 |
| 频率 | 保持全频带（建议 80 Hz–16 kHz 以上），不要预先做电话/留声机滤波 |
| 一致性 | 5 段必须同一次录制完成，情绪是连续的 |
