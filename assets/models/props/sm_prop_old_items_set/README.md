## 3. 技术规格

| 项目 | 要求 |
|---|---|
| 尺寸 | 单件 0.05–0.2 m；整套 5–8 件 |
| 单位 | 米；Y 轴向上；1 单位 = 1 m |
| 面数预算 | 1000–4500 tris |
| 材质槽 | 3–5 |
| 贴图 | 1K PBR |
| 碰撞体 | 小件通常不需要；需要拾取时用盒体代理 |
| 原点 / 朝向 | 单件底面中心 |
| 导出格式 | GLB / glTF |
| 运行路径 | public/assets/models/props/SM_Prop_OldItemsSet_01.glb |
