## 结论

**本资产不制作。** 世界观 V0.7 §3.4 已确认故事发生在 1897 年，宅内以煤气灯和早期电灯为主；1897 年没有现代便携手电筒。加入手电筒会破坏年代感，也与「灯光受限」的探索设计冲突。

黑暗区域改由以下方式处理：

- 场景内固定灯具与可交互开关；
- 壁炉、烛台、台灯等局部光源；
- 窗外月光与雾效提供最低可见度；
- 必要时用剧情演出或短暂闪光提示，不引入现代设备。
