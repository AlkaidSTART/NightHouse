# 场景文档

当前可运行场景为 `villa_greybox`，由 `src/game/scene/SceneManager.ts` 用基础几何体搭建，用于验证移动、交互、暂停和存档。

## 当前灰盒布局

- 房间：约 14 m × 12 m，层高 3 m。
- 玩家起点：`(0, 1.7, 4)`，面向 -Z。
- 北墙中央留门洞，无门。
- 已有占位家具：书桌、沙发、书架。
- 已有交互示例：桌上的字条。
- 灯光：一盏暖色点光、一盏冷色点光、一盏方向光。

## 正式场景需要补充

1. 确认区域列表：入口、客厅、走廊、书房、卧室、储物区、核心剧情区域。
2. 确认房间尺寸、墙体模块网格和门洞位置。
3. 确认玩家主路线、视线引导和区域解锁顺序。
4. 确认每个区域加载哪些模型、贴图、音频和灯光。
5. 确认碰撞体代理和不可通行边界。
6. 确认性能预算：同屏面数、材质槽数量、实时光源数量、贴图显存。

## 场景资源分组

| 分组 | 内容 | 加载时机 |
|---|---|---|
| core | 启动必需资源、UI、基础音效 | 进入游戏 |
| common | 常用材质、交互提示、通用道具 | 进入游戏 |
| scene_entry | 入口 / 门厅 | 进入区域 |
| scene_living | 客厅 | 进入区域 |
| scene_hall | 走廊 | 进入区域 |
| scene_study | 书房 | 进入区域 |
| scene_bedroom | 卧室 | 进入区域 |
| scene_storage | 储物区 | 进入区域 |
| npc_* | NPC 模型与动画 | 首次出现 |
| story_* | 特定剧情资产 | 剧情触发 |

具体区域名称和资源归属在关卡设计阶段冻结。
