# 特效

## 待建特效

| 优先级 | 资产 ID | 用途 | 实现 |
|---|---|---|---|
| P1 | FX_Rain_01 | 室外与窗面雨幕 | 分层粒子；控制数量，窗面可用滚动贴图 |
| P1 | FX_Fog_01 | 室外、崖边、窗边海雾 | 低浓度体积雾或粒子，避免高成本全局体积光 |
| P2 | FX_SeaSpray_01 | 崖边远景浪花 | 低频粒子，远距离弱化 |

特效密度与视距在灰盒和性能测试后冻结，不在每帧创建临时对象。

## FX_DustMotes

- 优先级：P2
- 用途：在低照度室内增加空气感和体积感。
- 实现方式：PlayCanvas 粒子系统 + 少量透明面片，不建议使用高成本体积雾。
- 参数建议：粒子数量 50–150，生命周期 6–12 秒，低速漂浮，跟随玩家相机区域。
- 性能：在目标设备上测量帧率后再决定是否启用；提供关闭选项。

## FX_Fog_LightShaft

- 优先级：P2
- 用途：窗边或门缝的局部光柱。
- 实现方式：低面数透明面片 + 柔和渐变贴图，避免实时体积光。
- 注意：透明排序和叠加数量要克制。

## 暂缓

在灰盒和核心剧情路线未确认前，不要投入大量粒子、体积雾或后处理特效。先保证稳定帧率和可读性。
