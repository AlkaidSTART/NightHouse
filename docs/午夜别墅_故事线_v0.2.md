## 1. 三幕结构

| 幕 | 时长（参考） | 空间 | 玩家目标 | 关键线索 | 幕末事件 |
|---|---|---|---|---|---|
| 第一幕：抵达与地面层 | 40–50 分钟 | 铁门、门厅、客厅、餐厅、走廊、书房 | 决定是否签署遗嘱；开始怀疑伊芙琳的死 | 停摆的钟、被剪的全家福、帆船油画、航运账本、保险赔付单 | 霍尔太太给出二楼钥匙 |
| 第二幕：二楼与真相 | 30–40 分钟 | 伊芙琳卧室、浴室、储物间、主卧（可选）、书房 | 拼出「意外死亡 + 掩盖」的真相 | 旧信、药瓶、浴室痕迹、行李箱、留声机蜡筒、船长日志、03:40 | 留声机录音；亚瑟在书房对质；午夜将至 |
| 第三幕：午夜与选择 | 15–20 分钟 | 门厅 | 在午夜前做出选择 | 遗嘱条款、全部已获证据 | 签字 / 拒签；结局演出 |

### 1.1 结构原则

- **不设可见的幕间标题。** 三幕是内部节奏，玩家感受到的是一夜连续的时间流。
- **每一幕都有独立的「表面目标」和「隐藏目标」。** 表面目标推动玩家行动，隐藏目标推动玩家怀疑。
- **每一幕结束时，玩家对真相的理解都必须发生变化。** 第一幕从「意外」到「可能是谋杀」；第二幕从「谋杀」到「意外与掩盖」；第三幕从「知道」到「选择」。
- **午夜不是计时赛。** 游戏不强制实时倒计时；午夜由关键事件推进触发，玩家可以按自己的节奏探索。

## 2. 开场：从铁门到门厅

### 2.1 设计原则

1. **玩家自己走进去。** 全程可控，不用过场动画剥夺控制权；只有黑屏读信和开门两个短瞬间可以限制移动。
2. **教学藏在环境里。** 第一个 `E` 是推开铁门，第二个是敲门，第三个是查看钟。不弹教程窗口，只在准星对准物体时给一行短提示。
3. **前几分钟不说话。** 从铁门到门廊，只有雨、风、碎石和远处的海。让房子先开口。
4. **第一个 NPC 在门后。** 门在玩家敲之前打开，霍尔太太已经知道他来了。
5. **第一个异常不是惊吓。** 钟停了，仅此而已；玩家自己意识到不对劲。

### 2.2 Beat 表

| Beat | 时间 | 玩家做什么 | 游戏给什么 | 目的 |
|---|---|---|---|---|
| 0. 黑屏与信 | 0:00–0:30 | 听 | 雨声、车轮声、主角读信的最后一句 | 建立动机与「十三下」规则 |
| 1. 铁门 | 0:30–2:00 | 下车、环顾、推开铁门 | 车夫离开；最简操作提示；铁门吱呀声 | 教学移动、视角、交互；建立孤立 |
| 2. 车道 | 2:00–3:30 | 沿车道走、查看环境 | 湿透的车辙、枯树篱、干涸喷泉、亮灯的窗 | 让玩家观察房子；建立空间感 |
| 3. 门廊 | 3:30–4:30 | 敲门、进门 | 门在敲之前打开；霍尔太太的第一句台词 | 第一个 NPC；第一个「他早知道你要来」 |
| 4. 门厅 | 4:30–6:00 | 看钟、看楼梯、和霍尔太太说话 | 停在 12:00 的落地钟；一声轻响后归于寂静 | 第一个异常；第一条规则 |
| 5. 客厅 | 6:00–10:00 | 见亚瑟与格雷、听遗嘱、选择是否出示信 | 被剪的全家福、遗嘱与笔、亚瑟的第一个谎言 | 建立三人关系；第一个可验证的裂缝 |
| 6. 自由探索 | 10:00+ | 探索地面层、对话、查看物品 | 门厅、客厅、餐厅、走廊、书房开放；二楼锁着 | 进入第一幕主循环 |

### 2.3 开场教学

| 时机 | 提示 | 形式 |
|---|---|---|
| 获得控制 | 「W / A / S / D 移动 · 鼠标 环顾 · E 互动」 | 屏幕下方一行，淡入淡出 |
| 看向铁门 | 「E 推开铁门」 | 准星旁的短提示 |
| 看向车道尽头 | 无提示；如果玩家往回走超过一定距离，显示「桥断了。天亮之前，没有马车。」 | 环境反馈 |
| 看向宅门 | 「E 敲门」 | 准星旁的短提示 |
| 看向钟 | 「E 查看」 | 准星旁的短提示 |
| 第一次和 NPC 对话 | 「E 交谈」 | 准星旁的短提示 |

不出现「按 ESC 打开菜单」之类的系统提示，除非玩家主动按 ESC。

### 2.4 Beat 1：铁门之外

- 画面从黑屏淡入。雨声先于画面出现。马车停在铁门外，车夫的轮廓在雨里。
- 车夫：「只能到这儿了。桥断了。天亮我再来。」马蹄声远去。
- 玩家获得控制。镜头面向铁门和坡上的宅子。铁门上的铜牌写着 **ASH CROFT HOUSE**，铜绿斑驳。
- 玩家可以环顾：湿透的车辙、枯死的树篱、远处崖下的海、亮着灯的窗户。宅子二楼有一扇窗没有亮。
- 铁门没有上锁，但很重。推开时铰链发出很长的吱呀声，盖过雨声。这是玩家制造的第一个声音，也是房子第一次「回应」他。

### 2.5 Beat 2：车道

- 车道两侧是湿透的草坪、一座干涸的喷泉、几尊被苔藓覆盖的石像。
- 宅子逐渐清晰：石墙、凸窗、铁艺阳台、陡坡屋顶。窗户亮着，但烟囱没有烟。
- 可查看的环境文本（各一句，不提供解谜信息）：
  - 喷泉：池底有一层枯叶，排水口被堵住了。
  - 石像：其中一个孩子的脸被风化得看不清。
  - 窗户：客厅的窗帘没拉严，能看到壁炉的火光。
  - 车辙：只有来时的车辙，没有离开的。

### 2.6 Beat 3：门廊

- 玩家走到门前，提示「E 敲门」。
- 敲门后有三秒的寂静，只有雨声。然后门从里面打开。
- 霍尔太太站在门里，穿深色裙子，手里拿着一盏灯。她看了玩家一会儿，说：
  > 「你来了。把外套给我吧，壁炉烧了很久了。」
- 玩家进门。门在身后关上，雨声突然被隔绝，门厅安静得能听见钟摆——但它没有在摆。
- 霍尔太太接过外套，挂在门边的铜钩上。她说：「少爷在客厅。」

### 2.7 Beat 4：门厅与第一个异常

- 门厅：深色木护墙板、楼梯、地毯、一面镜子、一张访客簿。尽头是那座落地钟。
- 钟停在 **12:00**，钟摆静止。钟面玻璃上有一层薄灰，但钟座底部有一道很细的缝。
- 玩家靠近时，能听见一声很轻的滴答，然后停了。不是钟摆的声音，更像某种机关松了一下。
- 玩家可以问霍尔太太：「钟怎么停了？」
  > 霍尔太太：「那晚。」
  > 玩家：「哪一晚？」
  > 霍尔太太不回答，转身去整理已经很整齐的访客簿。
- 楼梯通向二楼，但霍尔太太会说：「午夜之前，请别上楼。」如果玩家继续往上走，她会站在楼梯口，不闪避，也不解释。

### 2.8 Beat 5：客厅与第一个谎言

- 客厅：壁炉、沙发、茶几、边柜、半身像、帆船油画。壁炉上方是全家福。
- 亚瑟站在壁炉旁，手里拿着酒杯。格雷医生坐在扶手椅里，已经喝了酒，眼神有点散。
- 亚瑟：
  > 「我以为你不会来。」
- 他递给你一杯酒。玩家可以接、可以拒绝、可以不说话。
- 格雷抬头看你：
  > 「你小时候在这儿住过。那年夏天。」
- 然后他不再说话，看着火。
- 壁炉上方的全家福：伊芙琳的位置被剪掉了，留下一个方形的白痕。亚瑟说：
  > 「玻璃自己裂的。后来就收起来了。」
- 这是第一个谎言。后续可以通过储物间的剪刀或霍尔太太的证词验证：照片是被人用剪刀剪的。
- 桌上放着遗嘱、墨水瓶和笔。亚瑟解释：
  > 「父亲的遗嘱写得很清楚。午夜之前，必须有人代表家族签字。否则全部捐给海事孤儿院。」
- 玩家可以问伊芙琳、问遗嘱、问全家福、出示信，或者保持沉默。

### 2.9 Beat 6：自由探索

- 开放区域：门厅、客厅、餐厅、走廊、书房。
- 二楼锁着。霍尔太太在门厅附近活动，亚瑟在客厅，格雷在客厅和走廊之间走动。
- 第一个任务提示：「在午夜前决定是否签署遗嘱。」
- 隐藏目标：弄清伊芙琳发生了什么。

### 2.10 第一个异常：停摆的钟

- 钟是整栋房子的心脏，也是标题的来源。
- 第一次查看时，玩家只能看到：停在 12:00、钟摆不动、钟座底部有一道细缝。
- 第二次查看（或听完霍尔太太说「那晚」之后），可以听到一声很轻的滴答，然后机关松动的感觉。这是「回响」的第一条，但玩家不会立刻意识到。
- 钟的机关在后续谜题中打开；开场只负责让它「不对劲」，不负责解释。

### 2.11 第一个谎言：全家福

- 亚瑟说玻璃是自己裂的。
- 验证方式（任选其一）：
  - 储物间里有一把裁缝剪刀，刀刃上有相纸的碎屑。
  - 霍尔太太在信任后承认：「是夫人亲手剪的。剪完她就哭了。」
  - 照片背面的衬纸上留有剪裁的直线痕迹，不是碎裂的放射状裂纹。
- 这个谎言的作用不是让玩家立刻怀疑亚瑟杀人，而是让玩家意识到：**这家人会为了一件小事撒谎。**

### 2.12 信作为社交道具

| 对象 | 玩家的动作 | 结果 |
|---|---|---|
| 霍尔太太 | 出示信 | 她认出字迹，手会抖；承认信是她寄的；霍尔太太线打开 |
| 亚瑟 | 出示信 | 他说「这不是她的字」或「她那时已经不清醒了」；玩家第一次感到他在撒谎 |
| 格雷 | 出示信 | 他避开视线，说「我不该看这个」；不提供信息，但暴露他知道内情 |
| 所有人 | 不出示 | 保留到午夜，作为最后的筹码 |

信在物品栏中始终可读。出示信不消耗它。

### 2.13 不能离开

- 桥断了，马车走了，潮水在午夜满潮。
- 如果玩家走回铁门，显示：「桥断了。天亮之前，没有马车。」
- 不提供「离开」选项，也不让玩家在开场就触发结局。

## 3. 第一幕：地面层

### 3.1 空间与开放顺序

| 区域 | 开放条件 | 主要内容 |
|---|---|---|
| 门厅 | 开场 | 钟、楼梯、镜子、访客簿 |
| 客厅 | 开场 | 亚瑟、格雷、全家福、帆船油画、遗嘱 |
| 餐厅 | 开场 | 长桌、烛台、家宴的痕迹、遗嘱副本 |
| 走廊 | 开场 | 壁灯、装饰画、通往书房与后门 |
| 书房 | 开场 | 书桌、保险箱、账本、出诊记录、船长日志线索 |
| 二楼 | 霍尔太太给钥匙 | 卧室、浴室、储物间、主卧 |

### 3.2 第一幕关键线索

| 线索 | 位置 | 作用 |
|---|---|---|
| 停摆的钟 | 门厅 | 核心异常；机关伏笔 |
| 被剪的全家福 | 客厅 | 第一个谎言；家族抹除伊芙琳 |
| 帆船油画 | 客厅 | 船名与沉船日期；保险箱密码线索 |
| 航运账本 | 书房 | 家族负债与保险赔付 |
| 保险赔付单 | 书房 | 骗保的直接证据；埃德蒙的批注 |
| 格雷的出诊记录 | 书房 | 死亡时间矛盾 |
| 遗嘱副本 | 餐厅 | 孤儿院条款 |

### 3.3 第一幕 NPC 节奏

**亚瑟**
- 初始：礼貌、克制，像在主持董事会。
- 玩家问伊芙琳：他给一个体面的版本，强调她「不太稳定」。
- 玩家问全家福：他说玻璃自己裂了。
- 玩家出示信：他冷下来，但不发火。
- 玩家接近书房：他会找理由把玩家叫回客厅。

**霍尔太太**
- 初始：规矩、寡言，用「少爷在等您」结束对话。
- 玩家提到那个夏天：她的语气软下来，但不会立刻承认什么。
- 玩家出示信：她承认信是她寄的，但要求玩家「别让他知道」。
- 玩家帮她做一件小事（比如把煤油灯拿上楼、关窗）：信任度上升。

**格雷**
- 初始：回避、用医学术语转移话题。
- 玩家问伊芙琳的死因：他说「坠落与溺水，没有可疑之处」。
- 玩家问出诊记录：他会说「那是给老爷复诊」，但时间对不上。
- 玩家出示信：他避开视线，说「我不该看这个」。

### 3.4 幕末事件：霍尔太太给钥匙

触发条件（满足其一即可）：

1. 玩家在对话中提到那个夏天，并且没有对她撒谎。
2. 玩家出示信，并选择不指责她。
3. 玩家帮她完成一件与伊芙琳有关的小事（例如把伊芙琳的旧外套从门厅拿走、修好她房间的窗闩）。

霍尔太太的台词：

> 「二楼最里面是她的房间。钥匙在围裙口袋里。别让他知道是我给的。」

她把钥匙塞进玩家手里，然后转身去关门，不再看玩家。

## 4. 第二幕：二楼与真相

### 4.1 空间

| 区域 | 内容 | 关键线索 |
|---|---|---|
| 伊芙琳卧室 | 床、床头柜、衣柜、梳妆台、首饰盒 | 旧信、安眠药瓶、未寄出的信、被剪照片的另一半 |
| 浴室 | 浴缸、药柜、毛巾架、镜子 | 药瓶、带血的毛巾、排水口的头发 |
| 储物间 | 箱子、收纳柜、行李箱、旧衣物、船模 | 打包好的行李箱、剪刀、伊芙琳的旧外套 |
| 主卧（可选） | 埃德蒙的遗物、亚瑟的房间 | 埃德蒙的批注、亚瑟的失眠药 |

### 4.2 第二幕关键线索

| 线索 | 位置 | 作用 |
|---|---|---|
| 伊芙琳的旧信 | 卧室抽屉 | 建立主角与她的过去；情感重量 |
| 安眠药瓶 | 卧室床头柜 | 第 3 层误导：她被下药？第 4 层：她长期失眠 |
| 带血的毛巾 | 浴室 | 第 3 层：暴力；第 4 层：她跌倒后擦血 |
| 打包好的行李箱 | 储物间 | 第 3 层：她想私奔；第 4 层：她准备揭发后离开 |
| 裁缝剪刀 | 储物间 | 验证全家福是剪的，不是摔的 |
| 留声机蜡筒 | 书房 / 卧室 | 伊芙琳的留言；情感转折 |
| 船长日志 | 钟座暗格 | 沉船真相；骗保；03:40 的来源 |
| 四个船员的名字 | 钟座暗格 | 伊芙琳手写；情感落点 |

### 4.3 情感转折：留声机

- 玩家找到蜡筒后，可以在书房的留声机上播放。
- 录音内容（提案）：
  > 「如果你听到这个，说明我没来得及说。……别怪亚瑟。他比你想象的更害怕。……但那四个人，他们也有名字。」
- 录音不直接说出凶手，也不解释死亡经过。它只让玩家意识到：伊芙琳早就知道自己可能会死，并且留下了后手。
- 录音结束后，房间安静几秒，然后留声机自己转了一圈才停。这是「回响」，也是情感停顿。

### 4.4 对质：亚瑟

- **位置：书房。** 伊芙琳就死在这里；壁炉、书桌、保险箱、账本都在场。
- 触发条件：玩家持有至少两份关键证据（账本、船长日志、出诊记录、录音、霍尔太太的证词）。
- 分档反应：

| 玩家持有的证据 | 亚瑟的反应 |
|---|---|
| 只有账本 / 赔付单 | 承认骗保，但否认与伊芙琳的死有关；要求玩家「为了家族」签字 |
| 账本 + 出诊记录 | 开始动摇；承认那晚有争执，但坚持是意外 |
| 账本 + 出诊记录 + 霍尔太太证词 | 不再否认；说出「你非要把我们都毁了吗？」；不道歉，也不阻止玩家 |
| 全部证据 + 录音 | 沉默很久；只说一句「她不该留下那个」；然后离开房间 |

- 对质不改变结局条件，但改变结局演出的细节和玩家对亚瑟的理解。
- 对质结束后，亚瑟走出书房，把玩家留在原地。午夜将至。

### 4.5 钟的谜题：03:40

#### 物件来源

大厅的落地钟是从「珀耳塞福涅号」上拆下来的船钟。沉船后它被捞起，改装成落地钟，摆进门厅。它既是家族航运史的纪念品，也是罪证。

#### 为什么停在 12:00

伊芙琳在改装报时机关时把钟卡住了。她需要一个「停在某一刻」的假象，让家族以为钟早就坏了。

#### 解法

1. 在书房抽屉找到上弦钥匙。
2. 在船长日志（或船钟记录）里读到沉船时间：**03:40**。
3. 把钟拨到 03:40，上弦。
4. 钟敲十三下，钟座暗格弹开。

#### 为什么是十三下

伊芙琳在报时机构上多接了一个锤子。十二下是给活人的，第十三下是给那四个没能下船的人。这个动作不是诅咒，是纪念。

#### 暗格内容

- **船长日志**：证明珀耳塞福涅号被故意凿沉。
- **保险赔付单**：证明家族拿到了赔款。
- **一张折好的纸**：伊芙琳手写的四个船员名字。

#### 失败反馈

- 只拨到 12:00：钟摆不动，提示「发条是好的，但时间不对」。
- 没有上弦钥匙：钟座打不开，提示「锁着。钥匙不在这里」。
- 没有读到 03:40：玩家可以盲目试时间，但钟只在 03:40 触发；钟面下方有一道很细的刻痕，像是有人反复拨过这个位置。这个刻痕可以把玩家引回船长日志。

#### 与结局的关系

如果玩家打开暗格，掌握了船长日志和四个名字，「真相」结局的演出会更完整：报纸上会出现四个名字，玩家在午夜摊开证据时也更有分量。如果没打开，玩家仍可凭账本和证词拒签，但真相会更单薄。

### 4.6 幕末事件：午夜将至

- 玩家回到门厅。钟的状态、玩家持有的证据、三个 NPC 的位置决定第三幕的调度。
- 如果玩家已经打开暗格，钟座保持敞开，暗格里的东西可以被带到门厅。
- 如果玩家没有修复钟，钟保持沉默；玩家仍可做出选择，但「真相」结局会缺少最有力的一份证据。
- 霍尔太太把遗嘱重新摆好。亚瑟站在桌边。格雷在壁炉旁。午夜到了。

## 5. 第三幕：午夜与选择

第三幕的调度、物理选择、两个结局和最后一个镜头，见《世界观设定 V0.3》第 10.4–10.6 节。本节只补充叙事上的注意事项：

- MVP 先交付「签署（沉默）」与「拒签（真相）」两个结局；「部分真相 / 焚毁证据」作为后续扩展预留。
- 午夜前给玩家一段没有对话的独处时间，让他走一遍门厅、看一眼钟、听一次雨声。
- 亚瑟不阻止玩家，也不恳求；他只说那一句话，然后看着玩家做完。
- 霍尔太太在玩家做出选择后打开门，或转过身去。她的反应比台词更重要。
- 格雷在整个第三幕只说一两句话，最好都是职业性的、无用的安慰。
- 结局演出不解释超自然现象，只给一个镜头。
