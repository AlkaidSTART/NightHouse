# 《午夜别墅》调查线与剧情扩写 V0.1

**依据：** 《故事线文档 V0.7》《世界观设定 V0.7》《PRD V1.2》\
**目的：** 在不改变既有角色关系、死因、结局条件和核心事实的前提下，把已经写明但未进入玩法的细节补成可调查内容，并让玩家在进入书房对质前完成交叉验证。

---

## 1. 本轮解决的问题

原流程中，玩家只要拿到任意一条核心证据就能进入对质，导致：

- 医疗记录、浴室血迹、伊芙琳录音三条最能说明真相的线索可以互相替代；
- 书桌、卧室、浴室、保险箱和落地钟容易变成一次性打卡点；
- HUD 只告诉玩家“下一步去哪”，没有告诉玩家“还有哪些问题没回答”；
- 亚瑟的抓痕、返潮斗篷、第十三副餐具等双读细节缺少反馈闭环。

本轮将这些内容改为“主线门槛 + 可追踪调查线”，不增加新的核心剧情事实。

## 2. 调查线

| 调查线 | 关闭条件 | 主要地点 |
|---|---|---|
| 她真是坠海死的吗？ | 诊疗记录、浴室痕迹、格雷承认现场、问出格雷隐瞒动机 | 书房、浴室、门厅 |
| 亚瑟那晚在哪里？ | 左腕抓痕、返潮斗篷、承认在书房、承认忌日前去过崖边 | 客厅、门厅、书房 |
| 阿什克罗夫特家欠了什么？ | 油画日期、航运账本、保险赔付单 | 客厅、储物间、书房 |
| 伊芙琳留下了什么？ | 旧信、蜡筒、在书房听完录音 | 卧室、书房 |
| 第十三下从哪里来？ | 潮汐表、上弦钥匙、摆锤、修好落地钟 | 书房、卧室、门厅 |

调查线只由现有剧情标记和线索标记推导，不写入独立存档状态。这样读档后不会出现“调查线进度与线索日志不一致”的问题。

## 3. 主线门槛

对质前的关键步骤调整为：

1. 取得二楼钥匙，并问出霍尔太太看见的搬运经过；
2. 拿到诊疗记录和浴室痕迹，回门厅逼格雷承认死亡现场；
3. 去伊芙琳卧室找到蜡筒，在书房听完留言；
4. 打开保险箱，或修好落地钟并取得船长日志；
5. 回书房书桌整理证据；
6. 去书房对质亚瑟；
7. 午夜回门厅作出签署选择。

新增门槛使用“任选一条补充证据链”而不是强制全收集：主结局至少需要医疗真相、伊芙琳录音，以及账目或十三下钟声之一。调查线仍可用于引导玩家继续探索，并为强拒签证据和后续隐藏结局预留完整证据链。

## 4. 新增可玩细节

- 亚瑟讲述崖边经过时，左腕抓痕会进入线索日志。
- 门厅最里侧的旧斗篷会成为辅助线索，并可在后续对话中追问亚瑟。
- 霍尔太太会解释第十三副餐具、旧信和斗篷的来历。
- 格雷承认现场后，可以追问他是为了替伊芙琳保住名声，还是替阿什克罗夫特家保住体面。
- 旧信阅读后会改变钢琴的检视文本；听完录音后会改变家族照片与留声机的检视文本。
- 修好落地钟后，崖边纪念石会与船长日志中的四个名字形成呼应。
- 书桌抽屉在证据齐全后会变成“整理案情”的交互，并解锁对质。

## 5. 边界说明

本轮没有新增角色、改变凶手、改写死亡经过、增加 AI 对话、增加在线服务或改变结局路由。新增文本均服务于既有探索、NPC 互动、线索、谜题和剧情推进。
