## 1. 资产制作策略

### 1.1 总体原则

1. **先搭完整空间，再制作细节。** 优先完成室外抵达段、门厅、楼梯、客厅、走廊、书房和卧室的比例与动线。
2. **常见资产优先复用。** 桌椅、沙发、书柜、灯具等优先使用授权清晰的免费模型。
3. **生成额度留给独特资产。** AI 3D 生成优先用于落地钟、壁炉、保险箱、留声机、帆船油画等关键剧情资产。
4. **重复资产模块化。** 同一门型、窗型、踢脚线、餐椅和餐具尽量复用。
5. **优先 GLB / glTF。** 统一导入 PlayCanvas，减少格式转换成本。
6. **先低成本灰盒验证。** 场景比例、动线和视线确认后，再替换正式模型。
7. **资产必须服务剧情。** 新资产至少要服务探索、NPC 互动、线索、谜题或剧情推进之一，不为「可能用到」提前制作。

### 1.2 资产优先级

- **P0：** 缺少它就无法搭建、移动或完成核心交互。
- **P1：** 对场景氛围和叙事有明显帮助。
- **P2：** 主要用于丰富细节，可延期或删除。

### 1.3 状态标记

| 标记 | 含义 |
|---|---|
| 已有目录 | `assets/` 下已有资产 README，等待生成 |
| 待建 | 本版新增，尚无资产目录 |
| 修正 | 已有目录，但标题、规格或用途与 V0.7 文档不一致，已修正 |
| 暂缓 | 保留占位，当前阶段不制作 |
| 不制作 | 与时代、玩法或 MVP 范围冲突，明确排除 |

## 17. 建模与导入规范

### 17.1 尺寸与比例

- 统一采用米作为场景尺度基准。
- 门、桌椅、床等按现实比例制作。
- 玩家胶囊体高度与宽度在灰盒阶段冻结；门洞、楼梯踏步和家具间距以此为准。
- 模型原点应便于摆放、旋转和动画控制。
- 门的旋转枢轴应位于合页位置；抽屉、柜门、保险箱门、钟门同理。

### 17.2 模型规范

- 优先使用 GLB / glTF。
- 清理不可见内部面和重复几何。
- 检查法线方向。
- 控制材质槽数量。
- 避免不必要的高面数。
- 对重复资产使用同一模型或实例化；13 把餐椅、13 副餐具必须复用。
- 为需要碰撞的物体提供简化碰撞体，不直接用高精度渲染网格做复杂碰撞。
- 可交互模型必须提供稳定节点名，例如 `door_hinge`、`safe_dial`、`clock_minute_hand`、`secret_panel`。

### 17.3 贴图规范

- 常规家具优先使用 1K 或更低贴图，按视觉重要性决定。
- 关键近景资产再考虑更高分辨率。
- 复用材质和纹理集。
- 压缩纹理并检查浏览器端兼容性。
- 避免大量透明材质和高成本实时反射。
- 镜面使用简化反射或烘焙贴图；不要为每面镜子开启实时反射。

### 17.4 命名建议

``` text
SM_  静态模型
SK_  骨骼模型
MAT_ 材质
T_   贴图
TEX_ 2D 内容 / 文档贴图
AN_  动画
COL_ 简化碰撞体
FX_  特效
```

示例：

- `SM_Prop_LongcaseClock_01.glb`
- `SM_Prop_Phonograph_01.glb`
- `SM_Arch_Fireplace_01.glb`
- `SK_NPC_Housekeeper_01.glb`
- `AN_NPC_Idle_01.glb`
- `TEX_Document_TideTable.png`

## 18. 免费资源与授权检查

可优先从以下渠道筛选资源：

- Sketchfab：筛选可下载且许可符合项目用途的模型。
- Poly Haven：环境、材质、HDRI 等资源。
- Kenney：风格化与基础资源，需判断是否符合写实方向。
- ambientCG：PBR 材质与贴图。
- BlenderKit：检查具体资源许可和使用限制。

每个外部资源都应记录：

- 资源名称与来源链接；
- 作者；
- 许可证类型；
- 是否允许商业使用；
- 是否要求署名；
- 下载日期；
- 是否经过修改。

不得因为资源「免费」就默认可以商用。发布前逐项检查许可。

## 19. AI 3D 生成额度分配

建议按以下顺序使用有限生成额度：

1. 剧情独有、无法找到合适替代品的关键物品：落地钟、壁炉、保险箱、蜡筒留声机、帆船油画、全家福。
2. 具有强烈辨识度的特殊陈设：门厅楼梯、餐厅长桌、梳妆台。
3. 重要 NPC 的独特外观：亚瑟、霍尔太太、格雷医生。
4. 其他普通家具最后考虑。

不要用额度生成：

- 普通桌椅、床、书柜；
- 常规门窗；
- 大量相似书籍；
- 可用贴图表达的纸张文字；
- 可由 Blender 简单制作的基础几何体；
- 13 副餐具、13 把餐椅这类重复件（应复用）。

生成提示词应包含：物体类型、年代感、材质、磨损程度、尺寸比例、视角要求、背景要求，以及是否需要可用于游戏的干净拓扑。生成后仍需在 Blender 中检查比例、网格、材质和面数。

## 20. 资源预算与性能控制

## 22. 建模执行顺序

1. **灰盒：** 室外车道与门廊、门厅、楼梯、客厅、走廊、书房、卧室、餐厅、浴室、储物间、露台。
2. **核心结构：** 墙体、地板、天花板、门窗、楼梯、壁炉。
3. **核心剧情资产：** 落地钟、摆锤、上弦钥匙、保险箱、留声机、蜡筒、潮汐表、全家福、帆船油画。
4. **核心家具：** 客厅、餐厅、书房、卧室。
5. **NPC：** 三名角色模型、服装、Idle 与对话手势。
6. **次要剧情道具：** 行李箱、报纸、剪刀、船模、药柜、浴缸、梳妆台、纪念石。
7. **灯光、装饰和环境细节：** 灯具、挂画、地毯、摆件、雨雾。
8. **材质、磨损、污渍和氛围效果。**
9. **性能优化、资源压缩和最终验收。**

**资产冻结原则：** 在关卡平面和动线尚未确认前，不批量生成大量装饰资产。先完成灰盒、核心结构、核心剧情资产和三名 NPC，避免返工。
