# 《午夜别墅》结局文档 · 继承体面

**结局 ID：** `ending_signed`\
**版本：** V0.1\
**状态：** 主结局（MVP 交付）\
**依据：** [故事线文档 V0.7](午夜别墅_故事线文档_v0.7.md) §7、[世界观设定 V0.7](午夜别墅_世界观设定_v0.7.md) §10.5–10.6

> 本文是 `ending_signed` 的唯一权威演出文本。判定路由、条件与结局矩阵见故事线文档 §7；共享线索、谜题与对话见故事线文档 §3–§6。

---

## 1. 结局定位

玩家在午夜前签署遗嘱。家族保住体面与财产，玩家得到应得的部分，并成为新的守密人。真相没有被说出，房子留住了玩家。

**一句话主题：** 你继承了体面。

---

## 2. 触发条件与优先级

| 项目 | 内容 |
|---|---|
| 触发 | `choice.midnight = "sign"` |
| 优先级 | 最低。签署时 `ending_echo` 与 `ending_refused` 均不参与判定 |
| 互斥 | 与 `ending_refused`、`ending_echo` 互斥 |
| 证据要求 | 无。任意证据组合均可签署 |
| 钟状态 | 不要求修复。按世界观 §10.6，收尾仍有一次无法解释的钟声回响 |

---

## 3. 进入前必要状态

- 玩家已到达 B10 午夜节点（`story.midnight = true`）。
- 玩家在 `npc_arthur_midnight_01` 选择「签署」，设置 `choice.midnight = "sign"`。
- 不要求 `story.clock_repaired`、`story.safe_opened`、`story.heard_recording` 或任何对质标记。

---

## 4. 演出脚本

> 你在文件末尾签下「艾略特·维恩」。
>
> 亚瑟把纸收走，折好，放进内袋。「父亲会满意的。」
>
> 大厅的钟敲了。一下，两下……你没有数。到第十三下的时候，没有人抬头。
>
> 霍尔太太站在门边，看了你很久，然后低下头。
>
> 你拿到一笔钱，一栋你从不住的空房子，和一个每年十一月都要回来签字的理由。
>
> 天亮时雨停了。马车在桥那头等你。你回头看了一眼那栋房子。
>
> 纪念石上，伊芙琳的名字被海风吹得发白。

---

## 5. 结局字幕

「你继承了体面。」

---

## 6. 线索回收

- 全家福、十三副餐具、钟声、信。
- 若玩家已获得证据，旁白追加一句：「你把那些纸留在了书房。它们会一直在那儿。」

---

## 7. 统一收尾回响

按世界观 §10.6：沉默结局的收尾回响是「机关已拆，钟仍敲十三下」。本结局沿用该镜头，只给一次，不解释、不重复。

---

## 8. 验收清单

| 用例 | 预期 |
|---|---|
| 任意证据组合选择签署 | 进入本结局，不进入 refused 或 echo |
| 未修复钟 | 仍进入本结局；钟声回响按世界观 §10.6 处理 |
| 已获得全部证据 | 演出追加「你把那些纸留在了书房」 |
| 结局字幕 | 显示「你继承了体面。」 |
| 存档 | `choice.midnight = "sign"` 与结局 ID 正确记录（结局记录字段待补，见故事线 §11） |

## 9. 待确认

1. 结局后可操作项（返回主菜单 / 结局回顾 / 重新开始）与存档结局记录字段，见故事线文档 §7.5 与 §11。
2. 玩家未去过崖边时，「纪念石上伊芙琳的名字」旁白是否保留。建议保留，作为客观收尾，但需确认。
3. 钟未修复时的钟声。世界观 §10.4 写「钟保持沉默」，§10.6 统一规则写「每个结局都有一次回响」。本结局按 §10.6 处理，但两处措辞需统一。
