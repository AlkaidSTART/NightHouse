# 结局旁白规格：让她说话

> 状态：制作规格讨论稿，尚未录制或合成。

## 用途

为 `ending_echo` 的全部结局正文制作旁白。权威文本：[结局文档·让她说话](../午夜别墅_结局_让她说话_v0.1.md)。本文不复制剧情文本，以权威结局文档为准。

## 表演方向

- 叙述者：与其他结局一致的中性叙述者。
- 情绪：从门厅的克制和压迫，逐渐抵达名字被说出口的重量；结尾保留一线温度，但不读成胜利宣言。
- “塞缪尔·克罗斯，舱面学徒，十六岁”完整清晰；名字之间留小停顿，不额外添加角色配音或伊芙琳台词。
- 名字念完后约 1 秒完全静音，再进入十三下钟声。钟声尾音结束后，旁白继续讲述天亮后的余波。
- 对白与引号处理：待确认由旁白转述或保留角色原声。

## 交付建议

- 建议按自然段 / 情绪节拍切分，文件使用 `P01` 起连续编号。
- 建议运行文件：`public/assets/audio/vo/ending/VO_Ending_Echo_P01.ogg` 等。
- 源文件：WAV，48 kHz，24-bit；声道数与其他结局旁白保持一致；运行文件：OGG Vorbis。
- 干声优先；留声机带宽、底噪和空间距离由独立音效层处理，不烘焙进旁白。
- 钟声与旁白顺序、精确停顿和最终混音需按实际录音时长编排，不把不同段落烘焙成单一长音轨。

## 混音与时序

1. 走廊远处留声机空转声低音量出现。
2. 门厅段落时压低环境声，确保旁白清楚。
3. 旁白念完最后一个船员名字。
4. 留出约 1 秒静音。
5. 播放十三下钟声；第十三下轻微失谐且尾音更长。
6. 钟声尾音衰减后，旁白继续余下结尾；结束后留 2–3 秒低房间底噪，再进入结算。

## 验收

- 全部正文有旁白，字幕逐段与权威文本一致。
- 四名船员姓名、职务和年龄清晰准确。
- 最后一个名字与第一下钟声之间有明确静默。
- 第十三下不会被音乐、环境音或 UI 声遮挡。
- 静音或音频加载失败时，字幕可完整呈现。
