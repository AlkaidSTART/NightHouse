# 结局旁白规格：拒绝签字（弱变体）

> 状态：制作规格讨论稿，尚未录制或合成。

## 用途

为 `ending_refused` 弱变体的全部结局正文制作旁白。权威文本：[结局文档·拒绝签字](../../午夜别墅_结局_拒绝签字_v0.1.md) §7。本文不复制剧情文本，以权威结局文档为准。

播放顺序：先播放[共享真相回收旁白](ending-vo-truth-recap.md)，再播放本结局专属旁白。弱拒签专属段需明确说明主角知道发生了什么，但没有足够证据让其他人相信。共享段只制作一份资源，三个结局复用。

## 表演方向

- 叙述者：与其他结局一致的中性叙述者。
- 情绪：礼貌、疏离、冷静；不把亚瑟读成反派式威胁，重点是主角的拒绝没有产生影响。
- “十二下，不是十三下”前后留出清楚停顿；不要用恐怖音效强调。
- 段落间保留自然呼吸，最后一句“没有人再提伊芙琳”收得轻而确定。
- 对白与引号处理：待确认由旁白转述或保留角色原声。

## 交付建议

- 建议逐自然段切分，使用 `P01` 起连续编号。
- 建议运行文件：`public/assets/audio/vo/ending/VO_Ending_RefusedWeak_P01.ogg` 等。
- 源文件：WAV，48 kHz，24-bit；声道数与其他结局旁白保持一致；运行文件：OGG Vorbis。
- 干声优先，使用统一的近距离、低混响旁白处理。
- 结尾允许短暂冷雨或门厅底噪；钟声只响十二下，绝不补第十三下。

## 混音

- 旁白清晰度高于门锁、脚步和雨声。
- 钟声不与“十二下，不是十三下”旁白句子重叠，具体起点待试听和镜头节奏确认。
- 最后一句结束后保留约 2–3 秒低环境底噪，再进入结算；时长待试听确认。
