# 结局旁白规格：继承体面

> 状态：制作规格讨论稿，尚未录制或合成。

## 用途

为 `ending_signed` 的全部结局正文制作旁白。权威文本：[结局文档·继承体面](../午夜别墅_结局_继承体面_v0.1.md)。该文档是唯一台词来源；本文不复制剧情文本，避免两处文本漂移。

播放顺序：先播放[共享真相回收旁白](ending-vo-truth-recap.md)，再播放本结局专属旁白。共享段只制作一份资源，三个结局复用。

## 表演方向

- 叙述者：统一中性叙述者，不设定为艾略特的回忆。
- 情绪：克制、清楚、平静；读出“得到财产却继承沉默”的空洞，不讽刺、不煽情。
- 语速：自然偏慢；段落间保留约 600–1000 ms 呼吸空间，具体由试听调整。
- 重点：签名、无人抬头、每年回来签字、伊芙琳名字被海风吹白。
- 对白与引号处理：待确认由旁白转述或保留角色原声。

## 交付建议

- 建议逐自然段切分，文件按 `P01`、`P02` 顺序命名，便于字幕同步与单段重录。
- 建议运行文件：`public/assets/audio/vo/ending/VO_Ending_Signed_P01.ogg` 等。
- 源文件：WAV，48 kHz，24-bit，单声道或立体声待项目试听确认；运行文件：OGG Vorbis。
- 干声优先，房间感与轻微动态处理由运行时或统一后期完成；不要把过度混响烘入旁白。
- 峰值及响度目标需与其他结局旁白统一校准；正式数值待混音阶段确定。

## 混音

- 旁白优先级最高，纸张、笔尖、钟声和环境音均需自动或手动 ducking。
- 结尾最后一句后保留独立的结局余韵音效，不要让旁白尾音与 UI 点击声重叠。
