# 结局旁白规格：拒绝签字（强变体）

> 状态：制作规格讨论稿，尚未录制或合成。

## 用途

为 `ending_refused` 强变体的全部结局正文制作旁白。权威文本：[结局文档·拒绝签字](../../午夜别墅_结局_拒绝签字_v0.1.md) §5。本文不复制剧情文本，以权威结局文档为准。

播放顺序：先播放[共享真相回收旁白](ending-vo-truth-recap.md)，再播放本结局专属旁白。共享段只制作一份资源，三个结局复用。

## 表演方向

- 叙述者：与其他结局一致的中性叙述者。
- 情绪：前段克制而有压力；“伊芙琳的名字没有出现”之后降温；最后一句落在真相没有让任何人过得更好。
- 不做控诉式朗诵，不使用明显哭腔或预告片腔。
- 段落间保留自然呼吸；段落时长以情绪清晰为先，不强行压入固定秒数。
- 对白与引号处理：待确认由旁白转述或保留角色原声。

## 交付建议

- 建议逐自然段切分，使用 `P01` 起连续编号。
- 建议运行文件：`public/assets/audio/vo/ending/VO_Ending_RefusedStrong_P01.ogg` 等。
- 源文件：WAV，48 kHz，24-bit；声道数与其他结局旁白保持一致；运行文件：OGG Vorbis。
- 干声优先，使用统一的近距离、低混响旁白处理。
- 最后一句后留约 2–3 秒低环境底噪，再进入结算；时长待试听确认。

## 混音

- 旁白高于证据落桌、椅子移动、楼梯脚步和环境声。
- 可在“证据摆上桌”段落增加极轻纸张声，但不能逐句配动作造成广播剧感。
- 如使用钟声，严格遵循结局文档确认的收尾规则，不擅自更改钟声次数。
