# 结局冲击力升级计划（讨论稿）

> 状态：讨论中，尚未进入实现。
>
> 目标：在不改变现有结局 ID、核心事实和触发条件的前提下，提升结局的高级感、情绪起伏和余韵。核心提案是将结局正文改为完整旁白演出，并以音效、静默和节奏设计托住情绪。

## 已确认决策

- 三个结局均使用统一的中性叙述者讲述，不采用艾略特多年后的回忆口吻。

## 1. 当前判断

当前结局的主题和事实已经成立：

- `ending_signed`：玩家继承家族体面，成为新的守密人。
- `ending_refused`：玩家拒绝签字；根据证据进入强拒签或弱拒签。
- `ending_echo`：玩家完成完整证据链，让伊芙琳和四名船员被点名，并留下纪念石。

目前冲击力不足的主要原因不是结局事实不够严重，而是：

1. 关键动作之后缺少停顿，文本很快跳到多年后或天亮后的结果。
2. 在场人物的反应主要由旁白概括，玩家较少“听见”现场变化。
3. 三个结局都以文字面板直接收束，声音和空间余波不足；目前没有旁白承载结局正文。
4. 结算统计与返回首页操作过早出现，可能打断情绪。

## 2. 设计目标

### 必须达到

- 玩家能清楚感到“最后一个选择已经不可撤回”。
- 三个结局的正文都由统一旁白完整讲述，玩家仍可同步阅读字幕。
- `ending_echo` 的高潮集中在“旁白念出名字 → 空白 → 第十三下钟声”。
- `ending_signed`、`ending_refused`、`ending_echo` 的声音语义明显不同。
- 不新增角色，不接入外部服务，不改变结局判定路由。
- 音频来源、许可证和生成记录可追溯。

### 暂不做

- 不增加新的结局 ID。
- 不增加战斗、追逐或大型过场系统。
- 不把超自然现象解释成新的剧情事实。
- 不为制造冲击力加入未经确认的死亡、反转或角色自白。

## 3. 推荐方向：完整旁白先行，音效托住叙事

结尾的一大段文字全部拆分为旁白段落，由同一位旁白者讲述三种结局。旁白不只出现在隐藏结局高潮：从结局标题下的第一段正文开始，直到最后一句余韵都应有声音表达。原文继续作为同步字幕显示，保证静音游玩和无障碍阅读。

建议按自然段或情绪节拍切分音频，不逐句切得过碎。每段保留自然停顿，关键名字、关键选择和最后一句允许更长的呼吸；音效和音乐必须让位于旁白。优先先制作 `ending_echo` 的完整旁白样片，确认音色、语速与情绪尺度后，再批量制作另外两条，避免三条结局风格不一致。

### 3.1 旁白表演方向

- 统一叙述视角与音色，像在多年后回望那一夜，而不是播报结局摘要。
- 克制、清晰、亲近；情绪通过停顿、气息和少量重音传达，不使用夸张哭腔或预告片腔。
- `ending_signed` 读出被体面包住的空洞；`ending_refused` 读出真相与无力并存；`ending_echo` 从克制逐渐抵达“名字被听见”的重量。
- 对白仍作为旁白转述，不额外引入 NPC 配音，除非后续单独确认。
- 字幕与旁白内容保持一致；暂不改写文本来迁就配音。

### 3.2 `ending_echo` 声音节拍

建议制作一条约 25 秒的结局声音轨，或由独立音效按时间线播放：

| 时间段 | 声音 | 叙事作用 |
|---|---|---|
| 旁白进入门厅段落前 | 走廊尽头的留声机空转声，低音量 | 让伊芙琳仍像在现场 |
| 旁白念出最后一个名字时 | 环境声逐渐压低，旁白保持清晰 | 把注意力交给名字本身 |
| 名字念完后 | 约 1 秒完全静音 | 给玩家感受“已经说出口” |
| 随后 | 落地钟敲十三下 | 把四名死者从证据变成被点名的人 |
| 第十三下之后 | 长尾回响，随后恢复极低房间底噪；旁白再继续余下结尾 | 留下余韵，不立即结算 |

第十三下应与前十二下同音色但略微失谐、尾音更长；不使用恐怖惊吓音效或夸张音乐。

### 3.3 结局面板节奏

- 结局出现时开始播放旁白，并同步显示对应段落字幕；不立即显示线索统计。
- 旁白完成及结尾回响结束后，再显示调查总结和“返回首页”。
- 音频失败时仍正常显示全部文字，不阻塞流程。
- 提供明确的跳过旁白操作；跳过时停止当前旁白并进入结算，但关键停顿在正常播放路径中保留。

## 4. 三个结局的声音语义

### `ending_echo`：被记住

- 完整结局旁白 → 留声机空转声 → 关键名字由旁白说出 → 静音 → 十三下钟声 → 旁白余波。
- 重点是“点名”和“余波”，不铺满音乐。

### `ending_signed`：主动沉默

- 完整结局旁白；笔尖划过纸面、纸张折叠、遗嘱被收进内袋作为低音量点缀。
- 钟声听起来更远、更闷；第十三下不突出。
- 结尾保留房间底噪，不给情绪性解决。

### `ending_refused`：分裂的拒绝

- 强拒签：完整结局旁白；证据落桌、椅子移动、楼梯脚步远去作为低音量点缀，再进入天亮后的冷静余波。
- 弱拒签：完整结局旁白；门锁落下、脚步离开，只响十二下；不补第十三下。

## 5. 可选的故事微调

以下内容都不是第一轮必做项，必须逐项确认后才进入正式剧本：

### 方案 A：增加现场停顿（推荐）

在隐藏结局念完四个名字后，不新增台词，只增加三个人的动作停顿：

- 亚瑟没有反驳，手从遗嘱上移开。
- 霍尔太太的哭声被钟声盖住。
- 格雷医生没有马上承诺，只先摘下眼镜。

优点：不改变事实，改动最小，给音频留下空间。

### 方案 B：增加一句具体回收

保留现有孤儿院代表认出克罗斯的情节，但把它作为唯一明确的情绪落点。不得新增未经确认的身世或关系。

优点：让“被记住”落到一个具体的人身上；风险是削弱门厅高潮。

### 方案 C：增加一个新的反转

暂不推荐。会改变玩家对已确认事实的理解，容易扩大范围，也会削弱现有“真相不是解脱”的主题。

## 7. 验收标准

- 隐藏结局中，名字念完到第十三下之间存在可感知的静默。
- 三个结局的全部正文均有完整旁白，且与字幕逐段一致。
- 旁白清晰度高于音乐、环境音和音效；无对白或名字被音效遮挡。
- 第十三下不会被背景音乐或 UI 操作声遮住。
- 三个结局的声音层次能让玩家在不看标题时区分大致方向。
- 音频资源缺失或浏览器拒绝播放时，结局文字仍可完整阅读。
- 结局文本、触发条件、存档字段和现有自动化测试保持兼容。

## 8. 待讨论问题

1. 对白和引号内的直接引语，是由旁白者统一讲述，还是保留角色原声？
2. 隐藏结局是否坚持“旁白讲述主角念名字，但不新增伊芙琳台词”？
3. 是否接受旁白播放期间保留逐段字幕，播放结束后才显示调查统计？
4. 音频风格更偏真实历史质感，还是允许更明显的电影化混音？

## 9. 结局剧情增补候选（待确认）

这些候选只增加一个很短的现场动作或一句回收台词，不改变结局 ID、触发条件、人物关系、死因和既定结局事实。建议每个结局最多采用一个，避免结尾变成长过场。

### A. `ending_echo`：名字落在桌面上

十三下钟声结束后，旁白不立即跳到天亮。门厅保留一小段静止：亚瑟伸手想把遗嘱收回去，看到四名船员的名单压在下面，手停住；霍尔太太把第十三副餐具轻轻推回桌边。旁白随后进入孤儿院代表认出克罗斯的段落。

作用：把“被记住”与前面的十三副餐具、名单和门厅空间连起来，让隐藏结局的胜利不是抽象字幕，而是家族仪式被改写。

风险：需要一个很短的动作镜头或旁白动作描述；如果场景表现能力不足，可只保留声音和旁白停顿。

### B. `ending_signed`：把她的位置收走

签字和钟声之后，霍尔太太走到第十三个位置，把伊芙琳椅背上的灰羊毛披肩取下并折好。旁白不解释她的心情，只描述这个动作，然后进入“你得到一栋空房子”的段落。

作用：把“继承体面”的代价具体化为一次安静的抹除，回收开场和晚宴中已经出现的披肩与空位。

风险：需要确认“取下披肩”不会与既定的结局后状态冲突；不应写成伊芙琳的物品被永久处理。

### C. `ending_refused` 强变体：楼上的门

亚瑟走上楼梯后，旁白和脚步声都停下来。二楼传来一声门锁落下，之后再没有脚步。证据仍摊在桌上，格雷医生开始收拾眼镜或文件，旁白再进入天亮后的调查后果。

作用：让“亚瑟离开现场”变成不可逆的隔绝，强化真相被说出但没人得到解脱的主题。

风险：不能暗示亚瑟自杀、逃亡或新增结局事实；门声只能表达隔绝。

### D. `ending_refused` 弱变体：差一点说出口

走到门口时，霍尔太太像要叫出伊芙琳的名字，但最后只说“明早的马车在门口”。门关上，钟敲十二下。旁白保留最后一句“没有人再提伊芙琳”。

作用：用一个未完成的称呼表现“你拒绝了，但没有人听见”，不需要新增解释或证据。

风险：增加一句直接引语，需要统一由中性旁白讲述；不能让霍尔太太在弱变体突然完成证词。

### 推荐组合

第一轮建议只采用 A + B：隐藏结局获得一个“仪式被改写”的高潮，签署结局获得一个“记忆被收走”的代价。强、弱拒签先通过旁白、脚步、门锁和钟声完成，不急着加入新的台词。
