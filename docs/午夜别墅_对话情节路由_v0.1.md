# 午夜别墅 · 对话情节路由 v0.1

## 目的

对话树保存 NPC 的完整台词与分支；剧情路由决定玩家在当前任务步骤中实际进入哪个入口、能看到哪些追问。两层分离后，新增调查内容不需要改写场景站位或 React UI。

## 数据位置

| 内容 | 文件 |
|---|---|
| 任务步骤与推进条件 | `src/content/quests.ts` |
| 幕级标签 | `src/game/story/dialogueBeat.ts` |
| 步骤级 NPC 入口与话题白名单 | `src/content/dialogues/plotRoutes.ts` |
| NPC 完整对话树 | `src/content/dialogues/*.ts` |
| 入口解析 | `src/game/dialogue/dialogueEntries.ts` |
| 会话内过滤与锁定 | `src/game/dialogue/DialogueSystem.ts` |
| 对话面板 | `src/ui/dialogue/DialoguePanel.tsx` |

## 匹配顺序

`resolveDialogueEntry` 只使用当前任务的精确步骤 ID，不再用整幕代替步骤。候选路由按 `plotRoutes.ts` 中的声明顺序匹配：

1. `taskIds` 包含当前步骤；
2. `npcId` 相同；
3. 站位命中 `spotIds`，未声明 `spotIds` 时作为默认路由；
4. `when` 中的剧情条件全部满足。

同一 NPC 的多个条件变体按顺序排列，先满足者生效。例如午夜霍尔太太先匹配“已取得证词”的入口，再回落到普通入口。

## 话题白名单

`allowedChoiceIds` 只收窄当前步骤可展开的剧情追问：

- 未声明：不限制；
- 空数组：只保留导航选项；
- 有内容：保留白名单选项和导航选项。

`DialogueSystem` 始终保留结束对话（`next === null`）与 `back` 选项，避免剧情过滤把玩家卡在对话中。

会话打开时锁定任务步骤、节拍、白名单与目标提示。对话内写入剧情标记即使推进了任务，当前会话也不会突然混入下一任务的话题；关闭后再次交谈才切换到新步骤。

## 新增内容的检查项

- 任务步骤必须存在于 `quests.ts`；
- `nodeId` 必须存在，且节点 `npcId` 与路由一致；
- 白名单选项 ID 必须存在于该 NPC 的对话树；
- 新增步骤必须补充 `DIALOGUE_PLOT_LABEL`；
- 运行 `npm test`，其中会校验任务、NPC、节点、话题、条件与重复路由。
