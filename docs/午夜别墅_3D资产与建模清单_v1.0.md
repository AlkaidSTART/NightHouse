## 1. 资产制作策略

### 1.1 总体原则

1.  **先搭完整空间，再制作细节。** 优先完成墙、地板、门窗和房间比例。
2.  **常见资产优先复用。**
    桌椅、沙发、书柜、灯具等优先使用授权清晰的免费模型。
3.  **生成额度留给独特资产。** AI 3D
    生成优先用于关键剧情道具、特殊装饰或难以找到的模型。
4.  **重复资产模块化。** 同一门型、窗型、踢脚线和家具尽量复用。
5.  **优先 GLB / glTF。** 统一导入 PlayCanvas，减少格式转换成本。
6.  **先低成本灰盒验证。** 场景比例、动线和视线确认后，再替换正式模型。

### 1.2 资产优先级

-   **P0：** 缺少它就无法搭建、移动或完成核心交互。
-   **P1：** 对场景氛围和叙事有明显帮助。
-   **P2：** 主要用于丰富细节，可延期或删除。

## 3. 剧情道具清单

最终数量需由剧本确定，以下为候选类型，不代表全部必须制作。

  道具             优先级 资产要求             建议制作方式
  -------------- -------- -------------------- ----------------------
  日记本               P0 可近距离查看封面     简模 + 页面 UI
  信件 / 文件          P0 纸张模型或 UI 展示   平面模型 + 高清内容
  照片                 P0 可查看内容           平面模型 + 图片贴图
  钥匙                 P0 轮廓清晰             简单定制模型
  旧相框               P1 可替换照片内容       模型复用
  录音设备             P1 识别度明确           免费模型或简模
  特殊剧情物品       待定 由故事设定决定       优先使用 AI 生成额度

**节省建模量的做法：** 纸张、日记正文、照片细节可以通过交互 UI
展示，不必把所有文字真实建模在 3D 物体上。

## 4. NPC 资产清单

MVP 只制作剧情必需的少量 NPC。具体人数和人物设定以剧本为准。

每名 NPC 需要评估：

  资产                优先级 说明
  ----------------- -------- -------------------------
  人物基础模型            P0 统一比例、骨骼与材质
  Idle 站立动画           P0 基础待机
  对话动作                P1 手势、转头等，可复用
  行走动画                P1 仅当 NPC 需要移动时制作
  表情 / 面部动画         P2 可先用镜头和台词弥补
  独特服装与配饰          P1 优先体现身份差异

NPC 模型应优先考虑骨骼动画兼容性、面数和材质数量。不要在 MVP 阶段为每名
NPC 制作大量独立动作。

## 5. 灯光与氛围资产

灯具模型与实际光源建议分离管理。

  类型          使用区域               优先级 实现建议
  ------------- -------------------- -------- --------------------
  吊灯          客厅等                     P1 模型 + 静态烘焙
  壁灯          走廊                       P0 模型 + 少量光源
  台灯          书房、卧室                 P1 模型 + 局部光源
  手电筒        玩家视角（如启用）       待定 聚光灯与简单模型
  窗外环境光    全局                       P1 环境光与天空设置
  雾效 / 粒子   特定区域                   P2 少量使用，控制性能

## 6. 建模与导入规范

### 6.1 尺寸与比例

-   统一采用米作为场景尺度基准。
-   门、桌椅、床等按现实比例制作。
-   建模前先确定玩家胶囊体高度与宽度。
-   模型原点应便于摆放、旋转和动画控制。
-   门的旋转枢轴应位于合页位置。

### 6.2 模型规范

-   优先使用 GLB / glTF。
-   清理不可见内部面和重复几何。
-   检查法线方向。
-   控制材质槽数量。
-   避免不必要的高面数。
-   对重复资产使用同一模型或实例化。
-   为需要碰撞的物体提供简化碰撞体，不直接用高精度渲染网格做复杂碰撞。

### 6.3 贴图规范

-   常规家具优先使用 1K 或更低贴图，按视觉重要性决定。
-   关键近景资产再考虑更高分辨率。
-   复用材质和纹理集。
-   压缩纹理并检查浏览器端兼容性。
-   避免大量透明材质和高成本实时反射。

### 6.4 命名建议

``` text
SM_  静态模型
SK_  骨骼模型
MAT_ 材质
T_   贴图
AN_  动画
COL_ 简化碰撞体
FX_  特效
```

示例： - `SM_Furniture_Sofa_01.glb` - `SM_Prop_Diary_01.glb` -
`SK_NPC_Housekeeper.glb` - `AN_NPC_Idle_01` - `MAT_Wall_OldPlaster`

## 7. 免费资源与授权检查

可优先从以下渠道筛选资源：

-   Sketchfab：筛选可下载且许可符合项目用途的模型。
-   Poly Haven：环境、材质、HDRI 等资源。
-   Kenney：风格化与基础资源，需判断是否符合写实方向。
-   ambientCG：PBR 材质与贴图。
-   BlenderKit：检查具体资源许可和使用限制。

每个外部资源都应记录： - 资源名称与来源链接； - 作者； - 许可证类型； -
是否允许商业使用； - 是否要求署名； - 下载日期； - 是否经过修改。

不得因为资源"免费"就默认可以商用。发布前逐项检查许可。

## 8. AI 3D 生成额度分配

建议按以下顺序使用有限生成额度：

1.  剧情独有、无法找到合适替代品的关键物品；
2.  具有强烈辨识度的特殊陈设；
3.  重要 NPC 的独特外观（若免费资源无法满足）；
4.  其他普通家具最后考虑。

不要用额度生成： - 普通桌椅； - 常规门窗； - 大量相似书籍； -
可用贴图表达的纸张文字； - 可由 Blender 简单制作的基础几何体。

生成提示词应包含：物体类型、年代感、材质、磨损程度、尺寸比例、视角要求、背景要求，以及是否需要可用于游戏的干净拓扑。生成后仍需在
Blender 中检查比例、网格、材质和面数。

## 9. 资源预算与性能控制

本项目需要兼顾有限磁盘空间和浏览器端实时渲染。

建议： - 原始下载资产、编辑工程和最终运行资产分目录保存。 -
只保留实际使用的模型版本。 - 大型源文件可归档，不随 Web 构建一起发布。 -
贴图优先压缩。 - 按区域加载资源。 - 远景装饰优先使用低模或贴图表达。 -
关键区域完成后做一次构建体积检查。

推荐目录：

``` text
assets/
├── source/          # 原始下载与生成文件，不直接发布
├── models/
│   ├── architecture/
│   ├── furniture/
│   ├── props/
│   └── characters/
├── materials/
├── textures/
├── animations/
├── audio/
└── scenes/
```

## 11. 建模执行顺序

1.  灰盒：墙体、地板、门窗和房间布局。
2.  核心家具：客厅、书房和主要通道。
3.  关键剧情道具：日记、照片、钥匙等。
4.  NPC 模型与基础动画。
5.  灯具、装饰和环境细节。
6.  材质、磨损、污渍和氛围效果。
7.  性能优化、资源压缩和最终验收。

**资产冻结原则：**
在剧本和关卡布局尚未确认前，不批量生成大量装饰资产。先完成灰盒和核心道具清单，避免返工。
