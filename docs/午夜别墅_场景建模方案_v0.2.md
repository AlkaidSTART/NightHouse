### 1.2 文档之间的冲突

**D1：书房的楼层。✅ 已裁决为一楼。**

- 支持一楼：第一幕在拿到二楼钥匙之前就进入书房（C11）；霍尔太太开场就说「午夜之前，请别上楼」；亚瑟说「书房在走廊尽头」；终局在门厅能听到走廊尽头的留声机（C7）。
- 原先支持二楼的唯一依据是亚瑟在书房对质结束时说「去门厅吧，文件在楼下」（`npc_arthur_confront_break`）。该句已在故事线文档中改为「去门厅吧，文件在桌上」。
- C14 的「抬下楼」在一楼方案下仍然成立：浴室在二楼，浴室痕迹说明她受伤后在那里被处理过，所以路线是「书房 → 二楼浴室 → 下楼 → 一楼走廊 → 西侧露台」。

**D2：格雷医生的到场时间。❓ 待裁决。**

- 节拍表写 B4（19:40）格雷才到门厅。
- 但 §1.5 写客厅里格雷对主角说「你小时候在这儿住过」，§2.3 写 5–15 分钟在客厅「见亚瑟与格雷」，§1.6 的 B3（19:20）餐厅残席里格雷已经坐在桌边喝酒。
- 这直接决定客厅、餐厅、门厅各要预留哪些 NPC 站位点。本文在 §3 中把两种可能都列为站位点，等裁决后删掉一组。

- 沿用仓库现有约定：米为单位，Y 轴向上，现有灰盒中玩家面向 −Z 进入。
- **北 = −Z，南 = +Z，东 = +X，西 = −X。** 正门朝南，断崖在西。
- 原点 (0, 0, 0) 在门厅地面，正门内侧中轴线上向北 7 m 处。

## 3. 分区域建模规格

每个区域列出：固定陈设的位置、交互点、NPC 站位、灯光意图。交互点 ID 的命名规则见 §4.2；线索与资产的对应关系以资产清单 V1.1 §13 为准，这里不重复。

### 3.1 室外抵达段 `scene_gate`（P1）

- **陈设：** 铁门与门柱在车道南端；车道中段是干喷泉，两侧枯树篱兼作不可通行边界；门廊带雨棚和门廊灯。
- **外立面：** 只建南立面和可见的东西两侧转角，三层与屋顶用简化几何。北立面不建。
- **交互点：** 铜牌（观察）、铁门（推开）、正门（敲门）。
- **灯光：** 冷蓝月光方向光 + 门廊灯暖光；一、二层窗用自发光面片表现亮灯，伊芙琳卧室的窗不发光。
- **效果：** 雨、低浓度雾。进门后本区域整体卸载，只在室内窗外保留雨面片。

### 3.2 门厅 `villa_hall`（P0）

- **陈设：** 落地钟靠北墙偏西；U 形楼梯在东北角，第一跑沿东墙向北，第二跑沿北墙向西，接到北侧回廊；衣帽架在正门内侧西墙；玄关柜在东墙南段；签字桌在中央偏南；壁挂电话在走廊口旁。
- **交互点：** 落地钟（钟门、摆锤挂点、上弦、校时、暗格，按资产清单 §4 的四个节点）、衣帽架最里侧的斗篷、钥匙串、电话、签字桌上的遗嘱与笔（仅 B10 出现）。
- **NPC 站位：** 霍尔太太——正门内侧（B1）、走廊口（十三下后）、门边（B10）；亚瑟——回廊栏杆边（十三下后）、签字桌边（B10）；格雷——餐厅门口（十三下后）、楼梯口（B10）、正门内侧（B4，若 D2 裁决为 B4 才到）。
- **灯光：** 吊灯为主光（电灯，偏白的暖色）；楼梯和回廊各一盏壁灯；回廊上方保持昏暗。
- **状态变化：** 钟有「停摆 / 已装摆锤 / 走时 / 暗格弹开」四种状态；签字桌上的文件由剧情状态控制显隐。

### 3.3 客厅 `villa_parlor`（P0）

- **陈设：** 壁炉在西墙正中，炉台上放小座钟，上方刻箴言并挂全家福；帆船油画挂在北墙，靠近门厅一侧的门边，画框离墙留出可侧看的缝；钢琴在东南角；沙发、茶几、扶手椅围绕壁炉；边柜靠东墙。
- **交互点：** 全家福、箴言、帆船油画正面、帆船油画背面（独立交互点，站在侧面才能对准）、小座钟、钢琴。
- **NPC 站位：** 亚瑟——壁炉旁扶手椅或站立（B2）；格雷——另一把扶手椅（若 D2 裁决为开场即在）。
- **灯光：** 壁炉火光 + 一盏台灯；吊灯低亮度。全家福需要一盏能在玻璃上形成反光的灯，配合 `echo_photo_glare`。

### 3.4 一层走廊与二层走廊 `villa_corridor`（P0）

- **一层：** 笔直 7 m，北侧依次是储物间门、书房门，西端是露台门；南墙挂走廊镜和装饰画；窄长地毯。
- **二层：** 回廊接二层走廊；南侧最西端是伊芙琳卧室门，北侧是浴室门，另有 2–3 扇锁闭的门；墙上挂家族照片。
- **交互点：** 走廊镜（`echo_mirror_delay`）、露台门、各扇门、家族照片。锁闭的门交互时给出「锁着」的反馈，不静默。
- **NPC 站位：** 霍尔太太在一层走廊口有一个常驻点。
- **灯光：** 每 3 m 左右一盏壁灯（煤气灯，暖色低照度），两灯之间留暗区。

### 3.5 书房 `villa_study`（P0）

- **陈设：** 壁炉在西墙，石沿前是炉前地毯；书桌在房间中央偏东，面向门；保险箱嵌在北墙书柜下部；留声机在东墙边几上，喇叭朝向门；潮汐表挂在门边南墙；其余墙面是书柜。
- **交互点：** 潮汐表、书桌最下层抽屉（钟钥匙与诊疗记录，同一交互点分两次）、壁炉灰烬、石沿擦痕、炉前地毯、保险箱转盘、留声机。
- **NPC 站位：** 亚瑟——书桌椅（对质）；格雷——门外走廊（保险箱失败三次时的台词位）。
- **灯光：** 绿罩台灯（电灯）+ 壁炉火光。台灯要能被 `echo_study_lamp` 单独开关。
- **空间重点：** 壁炉石沿到书桌之间至少留出 2 m × 2 m 的空地。这是争执发生的位置，也是玩家重读线索时站的位置。

### 3.6 储物间 `villa_storage`（P1）

- **陈设：** 储物柜靠北墙，行李箱放在地面显眼处，旧报纸堆在架子下层，旧物箱（内有裁纸剪）在角落，船模在架子上层。
- **交互点：** 行李箱、报纸堆、旧物箱、船模。
- **灯光：** 一盏壁灯，无窗。

### 3.7 餐厅 `villa_dining`（P1）

- **陈设：** 长桌东西向，约 4.4 × 1.1 m，两侧各 6 席，西端主位 1 席，共 13 席；第 13 席是主位右手边第一席，椅背搭披肩；桌上有遗嘱副本、墨水瓶和笔；餐边柜靠北墙。
- **交互点：** 第 13 副餐具、披肩、遗嘱副本。
- **NPC 站位：** 亚瑟——主位；格雷——侧席；霍尔太太——门边（B3）。
- **灯光：** 桌面烛台为主，吊灯低亮度。
- **复用：** 13 把餐椅和 13 副餐具必须是同一模型的实例。

### 3.8 伊芙琳卧室 `villa_evelyn_room`（P0）

- **陈设：** 床靠北墙；床头柜在床东侧；衣柜靠东墙；梳妆台靠西墙，梳妆镜可从侧面看到镜框背面；南墙是窗（窗帘拉上，不透光）。
- **交互点：** 床头柜（日记、药瓶、干水杯）、衣柜（羊毛外套与摆锤）、梳妆台抽屉（蜡筒木盒、未写完的便笺）、梳妆镜背面（半张照片）。
- **灯光：** 默认只有走廊透进来的光和一盏可点亮的台灯。这是全宅唯一「没人住」的房间，照度应明显低于其他房间，但交互点必须看得清。

### 3.9 浴室 `villa_bathroom`（P1）

- **陈设：** 铸铁浴缸靠北墙；药柜与洗手盆在东墙；毛巾架在西墙；地面小规格瓷砖。
- **交互点：** 药柜（可开合）、毛巾架最里侧的旧毛巾、地砖缝里的暗痕。
- **灯光：** 一盏冷色调壁灯，是全宅唯一偏冷的室内光，配合 `echo_cold_spot`。

### 3.10 西侧露台 / 崖边 `villa_cliff`（P1）

- **陈设：** 露台石质栏杆；石阶向西下到崖边平台；纪念石在平台上，面向海。
- **边界：** 栏杆和崖边之外用不可见碰撞封闭，玩家不能坠落。海面只做雾和远景面片。
- **交互点：** 栏杆（`echo_cliff_song`）、纪念石。
- **灯光：** 月光 + 露台门内透出的暖光。

## 4. 制作与导入方案 ◐

### 4.1 三个阶段

| 阶段 | 做法 | 目的 |
|---|---|---|
| 灰盒 | 用代码按 §2.4 的尺寸表搭方盒墙体、楼梯坡道、门洞和占位家具，所有交互点和站位点就位 | 验证动线、视线、步行时间；这一步不消耗任何建模额度 |
| 结构替换 | 在 Blender 用模块化套件（墙、地板、天花、门框、门扇、窗、楼梯、壁炉）按区域拼装外壳，每个区域导出一个 GLB | 换上正式建筑，保持灰盒的尺寸和摆放点 |
| 陈设替换 | 家具和道具各自是独立 GLB，按区域 GLB 里的空物体摆放；可交互道具按资产清单要求拆出命名节点 | 逐件替换，任何一件缺失时仍显示灰盒占位，不阻塞整体 |

### 4.2 摆放点命名约定

灰盒阶段由代码给出这些点的位置；进入 Blender 后，由区域 GLB 里的同名空物体给出位置。游戏逻辑只认 ID，不关心位置来自哪里。

| 前缀 | 用途 | 示例 |
|---|---|---|
| `SPAWN_` | 玩家出生点、区域入口点 | `SPAWN_gate_start` |
| `INT_` | 交互点，后接交互对象 ID | `INT_prop_tide_table` |
| `PROP_` | 独立 GLB 道具或家具的摆放位置 | `PROP_SM_Furniture_Desk_01` |
| `NPC_` | NPC 站位，后接 NPC ID 与站位名 | `NPC_arthur_gallery_rail` |
| `DOOR_` | 门扇与合页位置，后接门 ID | `DOOR_study` |
| `TRIG_` | 进入触发体积 | `TRIG_hall_enter` |
| `ECHO_` | 回响的声源或触发位置 | `ECHO_mirror_delay` |
| `LIGHT_` | 光源位置，光照参数在代码侧配置 | `LIGHT_study_desk_lamp` |
| `COL_` | 简化碰撞盒（沿用资产清单 §17.4） | `COL_hall_wall_north` |

### 4.3 碰撞方案对建模的要求

现状：玩家只被一个矩形边界夹住，没有真正的碰撞；交互射线不判断墙体遮挡。正式场景必须补上。

推荐自写轻量碰撞，不引入物理库。它对建模提出四条硬性要求：

1. **所有墙体与坐标轴平行。** 凸窗、壁炉斜角等造型可以做，但对应的碰撞盒是包住它的矩形。
2. **每个区域 GLB 自带一组 `COL_` 盒子**，只用长方体，不用渲染网格做碰撞。
3. **楼梯的碰撞是两段斜坡加一个平台**，不是一级一级的台阶。
4. **家具碰撞每件 1–3 个盒子。** 小道具不做碰撞。

如果你更希望使用 PlayCanvas 自带的物理组件，需要引入 ammo.js，体积约 1–2 MB，属于新增依赖，按项目规则要先确认。

### 4.4 加载分组

- 室内是一个连续空间，房间之间不出现加载画面。
- 进入游戏时加载 `scene_gate`；敲门后加载室内公共部分和一层 P0 区域，门打开时完成切换，室外随即卸载。
- 锁着的区域（卧室、浴室、储物间、餐厅、书房）外壳随室内一起加载，内部陈设在门解锁时再加载，加载完成前门保持关闭。
- 崖边在露台门解锁时加载。
- 分组名沿用 `assets/scenes/README.md` 的 `scene_*` 表。

### 4.5 性能初始目标

以下是开工用的初始目标，不是测量结果。灰盒阶段和每次区域替换后都要在目标浏览器里实测，再调整。

| 项目 | 初始目标 |
|---|---|
| 单一视野三角面 | 不超过 30 万 |
| 单区域同时生效的局部光源 | 不超过 6 盏 |
| 实时阴影光源 | 全场景同时不超过 1 盏 |
| 默认贴图尺寸 | 1K；落地钟、全家福、帆船油画等近看的剧情件可用 2K |
| 镜面 | 走廊镜、梳妆镜、浴室镜都不做实时反射 |
| 透明材质 | 仅窗玻璃、雨、雾 |

静态光照是否烘焙、用什么方式烘焙，等结构替换完成后根据实测帧率再决定，本文不预设。

### 5.2 M1 灰盒结果（2026-11-11）

灰盒数据在 `src/content/scenes/villaGreybox.ts`，验收清单逐条写成了自动化测试（`tests/villaGreybox.test.ts`，`npm test` 运行）。

| 清单项 | 结果 | 说明 |
|---|---|---|
| 第一幕路线不上楼走完 | 通过 | 纯步行约 97 m，按步行速度 2.6 m/s 约 37 秒 |
| 第二幕路线 | 通过 | 门厅 → 卧室约 25 m（9 秒）；卧室 → 书房约 35 m（13 秒） |
| C5 三人同时可见 | 通过，有条件 | 要站在门厅中部。紧贴落地钟时玩家在回廊楼板正下方，看不到亚瑟 |
| C7 留声机声源方向 | 通过，已改写 | 签字桌到书房门的直线被门厅西墙挡住；实际通路是「签字桌 → 走廊口 → 书房门」，两段都无遮挡 |
| C2 不亮的窗 | 通过 | 从车道中段和喷泉旁都能看到 |
| 画框背面、镜框背面只能侧看 | 通过 | |
| 不穿墙、不坠落 | 通过 | 回廊、露台、崖边都测过 |
| 上锁的门有反馈且真的挡人 | 通过 | 6 扇剧情门 + 3 扇装饰门 |
| 隔墙不触发交互 | 通过 | 抽查了 3 处 |

灰盒暴露出的三个问题，留给人工走查时判断：

1. **宅子偏小。** 第一幕把所有房间走一遍只要半分多钟的步行时间，与世界观里「走廊长、房间多」的描述有差距。一层走廊只有 7 m。如果走查时觉得太紧凑，优先加长走廊，而不是加大房间。
2. **落地钟的位置。** 钟在回廊正下方，构图上进门就正对着它，但十三下响起时玩家必须后退几步才能看到亚瑟。如果希望一抬头就看到，可以把钟移到门厅西墙（走廊口与客厅门之间）。
3. **栏杆是实心方盒。** 灰盒里回廊栏杆高 1 m 且不透光，离回廊较近时会挡住亚瑟的上半身。正式模型用立柱栏杆后会改善，届时需要复测 C5。

以上数字来自自动化测试的几何计算。实际浏览器里只验证了「铁门 → 车道 → 正门 → 门厅」这一段，其余房间尚未有人实际走过。
